# Amazon Lucky Draw

واجهة قرعة ثابتة تعمل بالمتصفح، مناسبة للنشر مجاناً عبر GitHub Pages.

## الملفات
- `index.html` — هيكل الصفحة.
- `style.css` — التصميم الداكن المستوحى من ألوان Amazon.
- `script.js` — رسم العجلة، إدخال الأسماء، والدوران.

## تشغيل محلي
افتح `index.html` في المتصفح. يلزم اتصال بالإنترنت لتحميل خط Cairo من Google Fonts؛ وتعمل الصفحة أيضاً بخط بديل عند عدم توفره.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات الأربعة إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## ملاحظة حول قواعد القرعة
العجلة تعرض الخانات من 1 إلى 30، لكن اختيار الفائز يستثني الأرقام 17 و18 و19. هذه آلية مزحة/قرعة غير عادلة وليست مناسبة لأي سحب رسمي أو جائزة حقيقية. يمكن تغيير الأرقام المستثناة من `EXCLUDED_NUMBERS` في `script.js`.
